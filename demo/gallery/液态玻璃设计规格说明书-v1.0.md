## 规则一　只有悬浮的操作层使用玻璃

适用范围：以下规则用于实际界面的材质组合，不用于删减组件库的液态能力。Gallery 必须保留液态按钮、液态输入框、开关、滑块、选择器等示例，以及普通实色对照。紧凑尺寸与材质选择相互独立。

判断方法：**这个组件是不是浮在内容上方？**

| 判断 | 材质 |
| --- | --- |
| 是 | Liquid Glass |
| 否 | 普通材质 |

Gallery 的“透明”指**窗口内部的层间透明**：右侧原位、整宽矩形的浮动区域覆盖应用自己的滚动内容，
未滚动时，顶部与正文使用相同普通底色，连成完整表面，不显示阴影、高光或分界。
实际内容滚入顶部下方时，材质层才切换为 95% 不透明的液态，透出并模糊下层内容，不添加底部阴影。
回到顶部恢复完整平面。窗口底色始终不透明，不透出其他应用或桌面。
不另画内缩圆角块，不移动窗口装饰器。顶部按钮与下拉框使用轻档液态，左侧导航搜索保留液态输入。

## 规则二　默认避免叠玻璃，整块主区与液态操作控件可显式组合

| 场景 | 容器 | 内部组件 |
| --- | --- | --- |
| 普通 Dialog | 普通材质 | 普通按钮、普通搜索框 |
| 浮动搜索面板 | 轻玻璃 | 普通搜索框、普通列表 |
| Popover | 轻玻璃 | 普通按钮、普通列表 |
| 右侧原位整宽矩形浮动区域 | 材质层 95% 不透明，QML 模糊下方本应用内容，无底部阴影 | 装饰器保持原样；顶部按钮与选择器为轻档液态 |
| 嵌入式工具栏 | 普通材质 | 普通控件 |
| 左侧导航 | 普通材质 | 普通导航项，搜索框使用液态形态 |
| 控制中心 | 玻璃 | 普通控件为主 |

> **默认只强调一层玻璃。Gallery 窗内浮动区域的 95% 液态材质与顶部轻液态控件是明确允许的组合；不加额外圆角顶部块或控件阴影。**

## 规则三　颜色只有三族

不需要给每个组件单独设计颜色。所有颜色收敛为三族：内容、控件、玻璃。

| 族 | 用途 | 浅色主题 | 深色主题 |
| --- | --- | --- | --- |
| 内容 | 正文、列表、编辑器、内容面板 | `#FFFFFF` | `#1C1C1E` |
| 内容（次级） | 分组底、条纹区、次级面板 | `#F5F5F7` | `#242426` |
| 控件 | 普通按钮、搜索框、设置项 | `#EDEDF0` | `#3A3A3C` |
| 控件（Dialog） | Dialog 容器底色 | `#F7F7F9` | `#2C2C2E` |
| 玻璃 | 由背景决定（见下方 IF/ELSE） | 浅色自适应玻璃 | 深色自适应玻璃 |

### 3.1 Dialog 与按钮不共用同一底色

Dialog 和普通按钮同属控件族，但**不强制使用相同背景**。Dialog 是容器，按钮是容器内的控件，两者必须保留一级亮度差，否则按钮会陷进 Dialog 里：

| 主题 | 更亮的一方 | 取值 |
| --- | --- | --- |
| 浅色 | Dialog（容器） | `#F7F7F9` 亮于 `#EDEDF0` |
| 深色 | 按钮（控件） | `#3A3A3C` 亮于 `#2C2C2E` |

亮度差的方向随主题翻转，差值保持在“可辨”一级即可，不要拉到两级以上。

### 3.2 给 AI 的 IF / ELSE

```text
IF material == Glass
    background = AdaptiveGlass
    // 禁止用固定 RGB 代替玻璃

ELSE IF theme == Light
    content.background = #FFFFFF
    content.secondary  = #F5F5F7
    control.background = #EDEDF0
    dialog.background  = #F7F7F9
    search.background  = #EDEDF0

ELSE IF theme == Dark
    content.background = #1C1C1E
    content.secondary  = #242426
    control.background = #3A3A3C
    dialog.background  = #2C2C2E
    search.background  = #3A3A3C

ELSE
    background = SemanticColor
```

## 规则四　统一尺寸，不因玻璃改变大小

玻璃是材质，不是尺寸。同一组件换材质，尺寸不变。

| 属性 | 固定起点 |
| --- | --- |
| 正文 | 13px |
| 按钮、输入框及下拉框文字（含占位文字） | 11px |
| 普通按钮 | 高 28px |
| 搜索框 | 高 30px |
| 导航项 | 高 30px |
| 列表行 | 高 32px |
| 工具栏操作行 | 高 48px |
| 窗口装饰器行 | 高 30px，保持原位 |
| 基础间距 | 4 / 8 / 12 / 16px |
| 普通圆角 | 8px |
| 浮动容器圆角 | 12–16px |
