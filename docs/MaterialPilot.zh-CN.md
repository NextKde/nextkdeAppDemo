# 液态材质规格样板

> 历史样板记录。当前 Gallery 设计及实现值以 [Gallery 设计语言](GalleryDesign.zh-CN.md) 版本 2.10（2026-10-27）为准；下述旧尺寸、搜索强液态与多层阴影已被替代。

> 当前组合：原位整宽矩形浮动层以 95% 材质覆盖并模糊本应用内容，窗口保持不透明，不另划内缩圆角块，顶部控件采用轻档液态，左侧导航背景按新版规则采用整块普通面板、背景 opacity=.95 和 QML 同窗背景模糊，不做悬浮卡片或容器级液态效果，目录栏目不使用液态、条目保持普通填充，导航栏上的搜索框与操作按钮采用轻档液态；代码接入状态见设计语言文档。

## 2026-10-22 左侧导航行

最新用户裁决：导航搜索改回共享 LiquidTextField 液态形态（materialForm=false、liquidFinish=true、胶囊圆角），退出 plain 规格形态及其焦点外环。保留此前共享液态高光、填充、折射参数；搜索以用户明确指定的参考效果作为规格例外，其他导航行及侧栏背景不变。不截图或运行验证。

导航搜索焦点修正：通过现有 Gallery 的临时属性日志确认，系统accent为#1b2436，之前无彩色判断未排除这个近黑深蓝，实际焦点环仍取深色。增加HSL明度范围[.25,.85]，范围外仅焦点色回退#3478f6。热更新属性日志已确认focusedOutlineColor=#3478f6，临时诊断已移除；未截图、未做视觉验收。桌面规格书同步补充此边界条件，其他效果不变。

后续补齐整个导航内容：搜索启用共享 LiquidTextField 的 opt-in plain 规格形态，高34、圆角10、填充6%、焦点2px且偏移2；内边距16；主标题17/600、说明与分组11、正文14，文字层级 .92/.62。底部减少动态使用标准 Switch，开发指南使用 plain 操作行，取消额外液态。侧栏背景继续保留，不据此宣称整个侧栏材质已符合 regular/E2。其他页面和 KMusic 不变；用户自行查看热更新，未截图或运行验证。

改动：Gallery 左侧导航行 —— 启用共享组件的 opt-in specificationForm，移除行内独立玻璃，侧栏背景不变。其他应用默认行为不变。

层级：L1 侧栏内部 plain 行。

token：行高30、圆角8、正文14、selected tint .13、hover .06/.08、pressed .10/.12、pressScale .96、100/150ms、focus 2px / offset 2、disabled .38。

新增 token：无；规格值集中在组件的 specification 对象，未迁移其他控件。

玻璃预算：导航行新增持续0/2、瞬态0/1，现有侧栏背景保持原样。

Don't 自检：本次行材质无玻璃叠玻璃，不再全胶囊，不再按压膨胀。

未决：用户热更新验收；未截图、未构建、未运行验证。检查浅深色下行高、选中/hover/按压、Tab焦点及切换导航。

## 工具栏样板

2026-10-22：仅在 Gallery Buttons 页增加独立工具栏样板，原有示例保留作为对照。
不修改共享组件默认值，不修改 KMusic。用户负责运行和视觉验收。

改动：工具栏、按钮、输入框 —— 只有工具栏采样滚动内容，内部使用 Qt Quick Controls 的 plain 控件。

层级：工具栏 L1；内部控件不重复增加玻璃层。

token：toolbarHeight=44、toolbarRadius=20、toolbarInset=8；controlHeight=28、radius=10；regular 浅色白色 .58 / 深色 #1c1c1e .52；plainFill .04/.06、hoverFill .06/.08、pressFill .10/.12；输入填充 .06；label .92/.62；E2 两层阴影；focus 2px；按压 .96；100/150ms。

新增 token：样板集中在 `MaterialSpecTokens.qml`。sceneHeight=240 是展示区域尺寸；refraction=3、magnification=1.025、reflection=.50、backdropBlur=.20 保留既有光学参数，原因是先评审层级，不擅自覆盖此前确认的液态效果。shadow blur 通过 Qt DropShadow radius 表达，未经视觉标定。

玻璃预算：本样板持续 1/2，瞬态 0/1。原有对照区仍展示多个液态组件，不宣称整个 Gallery 已符合每屏预算。

Don't 自检：样板控件无嵌套玻璃；旧对照区保留原行为。光学参数暂以 §9 例外保留，不宣称完整符合规格。

未决：沿用对角高光，未替换为上左亮、下右暗；normalized blur 不等同已标定的20px；饱和度、噪声、亮度偏移、动态阴影倍率、增对比模式及全部状态尚未统一。减少透明度在此样板使用实心背景；减少动态时取消按钮缩放与颜色动画。未构建、未运行、未截图、未进行视觉验收。

用户检查：Buttons 页最上方样板；浅深色；样板内部滚动时图片与文字经过固定工具栏；输入、选择文字、清空；Tab 焦点与按压；关闭 Enabled；减少动态。下方现有版本用于对照。
