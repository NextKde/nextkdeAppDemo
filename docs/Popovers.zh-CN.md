# 带箭头的液态 Popover

[English](Popovers.md)

工具栏按钮打开的简短操作列表（例如日历顶部“＋”）使用 `LiquidPopover`，
箭头指向触发按钮。它是非模态操作选择弹层；选择“新建日程／提醒事项”后，
再打开锚定内容的 `LiquidContentPopover` 编辑，独立模态任务才用 `LiquidDialog`。菜单项不能套用主操作按钮的蓝色样式。

## 统一规格

- 面板与箭头使用一个连续轮廓、一层液态背景、一层柔和阴影。
  不另画实体三角形，不加接缝或强调色焦点框；允许调用处显式传入中性细描边。
- 面板圆角 12px；箭头宽 18px、高 8px；与触发按钮间距 4px。
- 玻璃层不透明度 0.95，与染色覆盖率、前景透明度分别控制。
  复用 `LiquidPanelSurface`：源模糊 0.85，浅色染色 0.18／深色 0.24，
  局部模糊 0.7、折射强度 8。禁止用 95% 实体染色盖住背景。
- 采样同窗口真实内容，排除弹层自身；用 QML 模糊和折射，不用 KWin 插件。
- 栏目使用普通材质：行高 30px、13px 普通字重、16px 图标、左右内距 8px。
  hover 和键盘高亮使用中性填充、6px 圆角；不加蓝底和边框。
- 面板内距 6px，箭头空间单独计算；文字和图标保持不透明。
- 减少透明度、缺失采样源或软件渲染时，降级为整体实体轮廓。

## 接入与交互

`anchorItem` 指向触发按钮，`sourceItem` 指向独立的页面场景，调用
`openAtAnchor()` 打开。默认居中置于按钮下方，距窗口边缘至少 8px；
下方不足时翻转到上方。箭头跟随触发位置并避开圆角。
Escape／点击外部关闭，保留 Menu/MenuItem 的键盘导航与激活。
栏目统一使用 `LiquidPopoverItem`，业务动作在应用的 `onTriggered` 中处理。

Gallery 的 Dialog 示例包含“操作弹层 → 编辑对话框”的完整入口。
当前使用面板与箭头的完整轮廓计算光学法线并裁切背景，圆角和箭头斜边共用
连续的折射、高光材质。

弹层宽度随最宽一项的文字／图标自然宽度，加栏目与面板内距自适应；未设置 iconName 时不留图标占位。简短操作菜单不使用固定宽度。

## 上下文内容与编辑面板（2026-10-28）

新建、查看、编辑上下文内容使用 `LiquidContentPopover`：非模态、不压暗背景，
锚定日程块或拖选范围。这覆盖前文笼统的“编辑打开 LiquidDialog”建议；
独立分类管理、确认等模态操作仍可使用 LiquidDialog。

设置 `anchorItem`，拖选范围可传该对象坐标系下的 `anchorRect`。
默认优先右侧，空间不足时翻到左侧，再选择上／下方；工具栏入口可设置
`preferredSide: "bottom"`。窗口内保留 8px 边距，箭头随锚点变化。
容器圆角 22px，玻璃背景沿用共同规格；内部浅灰分组和表单是普通材质。
Escape／点击外部关闭草稿不写入，保存／添加明确提交，保留验证及保存锁。
已有日程与提醒事项不能通过切换标签静默转换类型。

`LiquidPopover` 用于操作菜单，`LiquidContentPopover` 用于内容及编辑，
Gallery 的 Dialog 示例包含两者。箭头与圆角均参与轮廓光学计算。

## 背景可读性

`materialOpacity` 混合折射玻璃和已经模糊的底层，并不是纯色遮挡比例；
0.99 不代表遮住 99% 的背景。不要只靠增大它来消除编辑面板底下的文字。

`LiquidContentPopover` 分别提供 `backdropBlur`（0–1，默认 0.85）、
`blurStrength`（默认 0.7）、`tintStrength`（0–1，浅色默认 0.18、深色默认 0.24）。
日历的大尺寸新建／编辑面板当前分别设置为 1.0 / 1.0 / 0.42，
保留 `materialOpacity: 0.99`，其他 Popover 默认值不变。保留折射，内部控件
仍为普通材质。这组参数待虚拟机视觉验收：应保留背景色彩，但背景文字不能干扰
表单阅读，需覆盖深浅主题和密集文字背景。

## 可选细描边

`LiquidPopover` 与 `LiquidContentPopover` 支持 `borderWidth`（逻辑像素，默认 0）
及 `borderColor`（默认透明）。共享组件沿面板和箭头的完整轮廓绘制，调用处不能
另包矩形边框。日历编辑面板使用 0.5px：浅色黑色 12%，深色白色 18%。
描边与焦点、选中状态、材质不透明度无关。shader 已有方向性光学高光，
描边不能代替它。光学法线现在沿圆角、箭头斜边和主体边缘计算；细描边仍不能代替材质高光。

## 完整轮廓高光与窗口边界

`highlightStrength` 默认 0.32，设置为 0 关闭镜面高光；与 `borderWidth`、染色和
材质不透明度独立。Popover shader 计算最近轮廓及朝外法线，二次曲线圆角各以
16 段近似，同一法线同时驱动折射和窄边缘方向性高光。弹层旋转时光源保持在
场景左上方。箭头与主体共享模糊、染色、透明度和光学场。实体降级不宣称有采样折射。

当前容器使用 `Popup.Item`，位置限于宿主窗口；日历还限制编辑器高度并让表单
内部滚动。不能仅改成 `Popup.Window`：`LiquidBackdrop` 明确拒绝跨窗口采样。
后续独立弹窗需实现显式纹理传递、屏幕边界定位以及超出源窗口区域的降级策略，
不能假装可以采样桌面，也不能隐式依赖 KWin 液态插件。

Popover 阴影沿面板与箭头完整轮廓四周均匀扩散：水平／垂直偏移均为 0，不透明度 0.36，模糊 0.85，blurMax 48。

## 箭头定位与高表单

内容 Popover 的 `preferredSide` 支持 right、left、top、bottom，优先尝试指定方向、
相反方向，再尝试另外两侧。窗口边缘限制后，仅在面板仍位于来源之外，且箭头能准确
指向来源并避开两端圆角时显示；来源离开可视区域时隐藏，不能把箭头挤到错误位置。

两种 Popover 均提供 `arrowEnabled`（默认 true）和只读 `arrowVisible`。高度较大的
新建／编辑表单可以设置 `arrowEnabled: false`，日历的日程、待办编辑器采用此规则。
隐藏箭头同时移除箭头占位，保留液态材质、高光、阴影和非模态交互。小菜单在能准确
指向来源时保留箭头。验收需在虚拟机检查四个方向、窗口四角、缩放以及深浅色。
